# 二开锚点全量清单

本文件是 fork 二开锚点（`FORK-ANCHOR:` 标记）的唯一全量清单。锚点的作用、命名规则、
合并上游后怎么校验，见 `AGENTS.md` 第 2.0 节；这里只放清单本身。

当前共 **587 个** = 源码目录 572 个 + `.github/` 16 个。合并上游后逐个确认还在、且只出现一次。

统计命令（只数 git 已跟踪文件，因此 `node_modules` 等忽略目录里的缓存不会混进来）：

```bash
# 总数（排除 .md 文档；文档里只是在列举锚点名，不是改动点）
git -c core.quotepath=false grep -o "FORK-ANCHOR:" -- . | grep -v '\.md:' | wc -l

# 拆开看
git -c core.quotepath=false grep -o "FORK-ANCHOR:" -- . | grep -v '\.md:' | grep -v '^\.github/' | wc -l   # 应为 572
git -c core.quotepath=false grep -o "FORK-ANCHOR:" -- .github | wc -l                                      # 应为 16
```

`-c core.quotepath=false` 不能省：中文文件名的路径会被 git 转义成八进制，`grep -v '\.md:'` 就匹配不上，会多算。
